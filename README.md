# 五子棋游戏 (Gomoku)

一个基于 React + TypeScript 的五子棋游戏，支持人机对战和AI对战模式，采用高级 AI 算法。

## 游戏模式

### 人机对战模式 (PVE)
- 玩家执黑棋（先手）
- AI执白棋（后手）
- 可选择AI难度：简单、中等、困难
- 悔棋功能（撤销两步）

### AI对战模式 (EVE)
- 黑棋AI vs 白棋AI
- 可分别设置两个AI的难度
- 观战模式，自动下棋
- 悔棋功能（撤销一步）
- 适合学习AI策略和测试难度

## 游戏规则

1. **棋盘**: 15x15 格子
2. **玩家**:
   - 玩家执黑棋（先手）
   - AI执白棋（后手）
3. **下棋规则**:
   - 黑白双方轮流落子
   - 玩家只能在轮到自己时下棋
   - AI自动在轮到它时下棋
4. **胜利条件**: 率先在横、竖、斜任一方向形成连续五子者获胜
5. **悔棋**: 点击"悔棋"按钮可撤销玩家和AI各一步棋
6. **难度选择**: 提供简单、中等、困难三个难度等级

## AI 难度说明

### 简单难度
- **搜索深度**: 2层
- **候选走法**: 最多8个
- **计算时间**: <1秒
- **特点**:
  - 基础评估，准确度70%
  - 不使用威胁检测
  - 有30%概率随机选择次优走法
  - 适合新手练习

### 中等难度（默认）
- **搜索深度**: 3层
- **候选走法**: 最多12个
- **计算时间**: <2秒
- **特点**:
  - 标准评估，准确度90%
  - 启用威胁检测和防守策略
  - 识别常见棋型
  - 适合休闲娱乐

### 困难难度
- **搜索深度**: 6层
- **候选走法**: 最多20个
- **计算时间**: <5秒
- **特点**:
  - 完整评估，准确度100%
  - 完整威胁检测（包括冲四防守）
  - 高级攻防策略
  - 组合棋型识别（双活三、活四+活三等）
  - 主动进攻策略
  - 多个防守走法时智能选择最优
  - 接近专业水平，极具挑战性

## AI 算法特点

### 核心算法
- **Minimax 算法** + **Alpha-Beta 剪枝**
- 搜索深度：3 层（优化后，避免页面无响应）
- 剪枝效率：60-90%
- 时间限制：最多2秒计算时间

### 评估系统
- **棋型识别**（7种棋型）：
  - 连五：100000分（胜利）
  - 活四：10000分
  - 冲四：1000分
  - 活三：500分
  - 眠三：50分
  - 活二：10分
  - 眠二：1分

- **位置权重**: 中心区域优先
- **攻防平衡**: 防守权重为进攻的1.1倍

### 智能优化
- **威胁检测**: 优先识别必杀和必防走法
- **走法优化**: 只搜索已落子周围2格范围
- **走法排序**: 优先搜索高分走法，提升剪枝效率
- **性能优化**:
  - 限制候选走法数量（顶层15个，深层10个）
  - 时间限制保护（2秒超时）
  - 异步计算，避免阻塞UI线程
  - 错误恢复机制

## 代码规则说明

### 严格遵循五子棋规则

修复了以下问题，确保游戏严格遵循五子棋规则：

1. **移除了 `makeMove` 的 `player` 参数**
   - 之前：`makeMove(position, player?)` 允许指定下棋玩家
   - 现在：`makeMove(position)` 只能按 `currentPlayer` 下棋

2. **确保黑白交替**
   - 玩家（黑棋）只能在 `currentPlayer === Player.BLACK` 时下棋
   - AI（白棋）只能在 `currentPlayer === Player.WHITE` 时下棋
   - 每次下棋后自动切换 `currentPlayer`

3. **AI 算法适配**
   - Minimax 搜索时严格按照 `currentPlayer` 模拟
   - 威胁检测使用临时克隆的 GameState
   - 走法排序基于当前玩家
